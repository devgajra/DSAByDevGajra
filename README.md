# 📖 Structure of Every Problem

Every problem has its own dedicated folder.

```
Problem Name
│
├── README1.md // in english
├── README2.md // in hinglish
└── solution.cpp
```

### 📄 README.md

- Problem Statement
- Intuition
- Brute Force
- Better Approach
- Optimal Approach
- Dry Run
- Time Complexity
- Space Complexity

### 🇮🇳 README_HI.md

The complete explanation in **Hinglish** .

### 💻 solution.cpp

Contains all possible approaches for the problem:

- Brute Force
- Better Solution
- Optimal Solution
